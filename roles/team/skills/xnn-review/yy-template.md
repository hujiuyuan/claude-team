# X-NN-YY 通用模板（没有样板时使用）

一个 YY 对应一次独立提交。目标仓库有样板时，以样板为准；本模板里的必备内容并入样板对应的章节。

```markdown
# <X-NN-YY> <标题>

> 父文档：<X-NN 及章节>｜PRD：<条目>｜前置：<YY 列表或“无”>｜降级标注：<无 / 未对照代码 …>

## 目标
一句话：这次提交完成后，什么行为成立。

## 动作
1. <文件或模块>：<具体改什么>（函数、接口、字段）
2. …

## 接口与数据变更
- 接口：方法、路径、请求和响应字段、错误码
- 数据：表或字段的变更、迁移脚本

## 测试
- 新增或修改的用例：正常、异常、边界

## 验证
- 命令：
- 预期结果：

## 回滚

## 提交信息
```
