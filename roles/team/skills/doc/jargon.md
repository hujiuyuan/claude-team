# 黑话表

摘要里不许出现左列的词，换成右列的说法。我说哪个词看不懂，就往这里加一行。

| 黑话 | 换成 |
|---|---|
| 落盘 | 写进文件 / 保存下来 |
| 卡口 | 必须先过的检查 |
| 锚点 | 文档里引用的具体位置 |
| 回链 | 指回原来的出处 |
| 闭环 | 从开始到结束都处理完 |
| 口径 | 统计或判断的标准 |
| 真理源 | 以哪份为准 |
| 影响面 | 会影响到哪些地方 |
| 兜底 | 出问题时的备用办法 |
| 幂等 | 重复操作结果不变 |
| 预加载 | 启动时自动读入 |
| 硬约束 | 必须遵守的规则 |
| 流水线 | 按顺序的几步 |
| 子代理 / agent | 派出去干活的另一个 AI |
| skill / 技能 | 写好的做事说明 |
| hook | 自动执行的检查 |
