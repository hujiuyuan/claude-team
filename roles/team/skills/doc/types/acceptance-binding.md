# 项目绑定模板

每个项目填一份，放在项目里（建议与验收文件同目录，文件名“项目绑定.md”），并在项目 CLAUDE.md 里留一行指针。

| 字段 | 填什么 |
|---|---|
| 验收文件放哪 | 目录与命名规则，附一个例子 |
| 被验设计文件在哪、怎么命名 | 目录规则、编号规则的出处 |
| 外部接口 → 设计文件 | 文件命名或位置 |
| 服务间接口 → 设计文件 | 如何区分（路径前缀、文件头标记） |
| 定时任务 → 设计文件 | 文件命名或位置 |
| 消息消费 → 设计文件 | 文件命名或位置 |
| 需求文档位置 | 路径；页面或条目怎么定位；需求条目的编号写法（如 R1、E01）；没有落点时回链怎么写 |
| 接口编号格式 | 写在设计文件的哪里 |
| 错误码表位置 | 路径与检索方式 |
| 测试命令 | 从哪个目录跑；有哪些坑 |
| 提交信息风格 | 格式；提交方式上的限制 |
| 登记要求 | 新增文档是否要登记台账、更新编号规则 |
| 决定记录放哪 | `team:deliberate` 用：目录；文件名 `<日期>-<问题短名>.md` |
| 用户保留的拍板项 | `team:deliberate` 用：清单位置；命中的不辩，直接上报 |

项目没有的触发方式，对应行填“无”。
